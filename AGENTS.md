# Modular Backend Starter

Este repositorio es un template independiente de backend. La aplicación npm vive en `server/`.

- Antes de modificar `server/`, leé `server/AGENTS.md` y `server/README.md`.
- Ejecutá instalaciones y checks desde `server/`, no desde la raíz.
- Conservá `.git`, `.github` y la licencia en la raíz; no agregues un paquete npm raíz sin requerimiento.
- Mantené CI, Dependabot y Husky alineados con `server/`.
- No agregues frontend ni dependencias del template fullstack.
